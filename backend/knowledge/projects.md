MultiGame is a cross-platform gaming app I'm currently building with Flutter. It brings together five games — Sudoku, Snake, 2048, a puzzle game, and an infinite runner — all under one roof with unified state management and the Flame game engine. It's a passion project that combines my love for gaming with my mobile development skills. The app is deployed on GitHub Pages with a full CI/CD pipeline using GitHub Actions for automated Flutter web builds.

HelpDesk Pro is an enterprise-grade ticketing system I built using the MERN stack — MongoDB, Express, React, and Node.js. The standout feature is Keycloak integration for Single Sign-On and role-based access control, which gave me deep experience with identity management in real-world applications. I wrote a JUnit test suite for the backend APIs and containerized all services with Docker to ensure consistent deployment environments. It was completed in January 2026.

MediGuide is an AI-powered multilingual medical chatbot I built using Flask on the backend and React on the frontend, integrating the Grok API for context-aware symptom triage and health information queries. I designed the MongoDB schema for medical FAQs and conversation histories, and containerized the whole system with Docker. It was an early deep dive for me into AI integration and multilingual UX design, completed in June 2025.

iTeamHub is a mobile social platform I built for students using Flutter on the frontend and Express.js with JWT authentication on the backend. It supports posts, comments, real-time notifications via Firebase Cloud Messaging, and role-based access control. I designed the full MongoDB schema for users, posts, and threaded comments with a relational-style architecture. It was a great exercise in building a feature-rich mobile app end to end, completed in November 2024.

Co-op Brand Platform was a full-stack web application I built as part of an academic team project. It connects influencers with brands for product collaborations, built with React on the frontend and Node.js with Express on the backend, using MongoDB for data storage. I was responsible for building the RESTful API for authentication and profile management, as well as the campaign dashboard and search functionality on the frontend. It was my first serious team-based full-stack project, completed in June 2023.
